# 제목 위 라벨 가독성 개선 설계

## 목표

대제목·중제목·소제목 위에 표시되는 문맥 라벨과 단계 번호를 현재 12px보다 크게 표시해, 모바일과 데스크톱에서 한눈에 읽히도록 한다.

## 확정안

- 전용 글자 크기 토큰 `--fs-label: clamp(14px, 1.4vw, 16px)`을 추가한다.
- 모바일에서는 최소 14px, 넓은 화면에서는 최대 16px로 표시한다.
- 모노스페이스 글꼴, 자간, 색상, 대문자 표현은 현재 디자인을 유지한다.

## 적용 대상

- 섹션 제목 위 라벨: `.sec-head__eyebrow`
- 서비스 카드 번호·분류: `.card__no`
- 홈페이지 실제 도구 사례 번호: `.home-case__number`
- 도구 상세 사례 번호: `.case-detail__number`
- 교육 과정 시간 라벨: `.course-summary__hours`

## 제외 대상

시간·기간 이외의 세부 메타데이터, 각주, 이미지 설명, 푸터 저작권, 표 안의 보조정보는 기존 `--fs-micro: 12px`을 유지한다. 제목 위계가 뒤집히지 않도록 h1·h2·h3 크기와 간격은 변경하지 않는다.

## 검증 기준

- 360px 화면에서 적용 대상이 14px 이상이어야 한다.
- 1280px 화면에서 적용 대상이 16px 이하여야 한다.
- 제목·본문·버튼 줄바꿈과 수평 오버플로가 새로 생기지 않아야 한다.
- 홈페이지, 교육, 도구, 문의, 프로필의 대표 라벨을 데스크톱·모바일 캡처로 비교한다.
- 기존 Node 테스트와 전체 브라우저 검수 하네스가 통과해야 한다.
